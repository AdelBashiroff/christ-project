Наш продукт — компактное приложение-справочник христианских писаний, удобная альтернатива бумажным книгам для быстрого доступа к священному тексту.

Кому будет полезен наш продукт:

* Священники и служители церкви
* Преподаватели воскресных школ
* Студенты духовных семинарий
* Люди, интересующиеся Библией
* Исследователи религиозных текстов

Приложение «Справочник священника» — это карманный гид по христианским писаниям.

Ключевая ценность: функция «Случайное писание» помогает пользователям получать мудрые наставления одним кликом, а AI-помощник поможет разобраться в контексте.

Возможности:

* Автономность
* Поиск и навигация
* Данные в одном месте
* AI-интеграция

Ограничения:

* Только русский язык
* Ограниченный набор текстов
* Нет полной Библии
* Риск потери данных
